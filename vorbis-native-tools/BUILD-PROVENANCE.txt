WHY THIS FILE EXISTS
--------------------------------------------------------------------------------
A binary in a package is anonymous. This file is how anyone later can tell which
native library came from which source, which toolchain and which build machine.
Every time a binary is adopted into ../src/CodeBrix.Audio.Vorbis/runtimes/<rid>/
native/, its section here is updated from that build's output/<rid>/BUILD-INFO.txt.

Common to every entry below
--------------------------------------------------------------------------------
  Source          : ogg/ (libogg 1.3.6) and vorbis/ (libvorbis 1.3.7) - the
                    unmodified Xiph release tarballs (upstream-downloads/;
                    sha256 5c8253428e18...1061 / b33cc4934322...954b; see
                    UPSTREAM.txt), plus shim/codebrix_vorbis.c implementing the
                    fixed contract shim/codebrix_vorbis.h (API version 1)
  Compiled        : libogg bitwise.c framing.c; libvorbis lib/*.c incl.
                    vorbisenc.c; NOT vorbisfile.c. All statically linked into ONE
                    shared library per RID via shim/CMakeLists.txt.
  Visibility      : -fvisibility=hidden for every object (+ --exclude-libs,ALL on
                    Linux/Android); exports are EXACTLY the 11 functions of
                    codebrix_vorbis.h - checked by every gate (missing AND extra)
  Patches applied : NONE. patches/ is empty.
  Shipped names   : libcodebrix_vorbis.so / codebrix_vorbis.dll /
                    libcodebrix_vorbis.dylib - unversioned (SONAME/install name
                    unversioned too), because DllImport("codebrix_vorbis") probes
                    exactly those names
  Licences beside : LICENSE-Vorbis.txt = licenses/LICENSE-Vorbis.txt, composed by
  every binary      licenses/compose-license-vorbis.sh from vorbis/COPYING + a
                    separator + the third-party notice PRESERVED in
                    vorbis/lib/lpc.c (Jutta Degener and Carsten Bormann, TU Berlin
                    1992-1994; the block "/* Some of these routines" ..
                    "Carsten Bormann", lpc.c lines 17-41), whose condition is that
                    it is not removed. LICENSE-Ogg.txt = ogg/COPYING verbatim.
                    Identical on all nine RIDs (md5 of LICENSE-Vorbis.txt
                    eaa25e8550ce001cf34b0311c13a870d). Every bash gate re-runs the
                    generator and compares; the Windows gate checks the committed
                    file and its COPYING prefix. .gitattributes keeps these texts
                    byte-identical on Windows checkouts (-text).
  Smoke test      : ../smoke-test.c, compiled for the target and run against the
                    STAGED (stripped) file: api_version == 1, libVorbis 1.3.7
                    version string, 1 s 440 Hz stereo 44.1 kHz q0.4 encode in 6
                    uneven chunks, every Ogg page walked ("OggS" at 0, BOS on
                    first page only, EOS on last page only, one serial, last
                    granule == 44100), plus the contract's error paths and a
                    headers-only stream that still ends in EOS. 47 checks.

Linux (the three linux-* entries)
--------------------------------------------------------------------------------
  Route           : linux/build.sh <arch> -> container-build.sh inside
                    codebrix-vorbis-build-<arch> (Containerfile.<arch>: the
                    digest-pinned manylinux base + a toolchain PROBE; NOTHING is
                    installed, so the image build also ran with --network none),
                    run with --network none, --pull=never
  Build host      : Dell Precision 7770, LMDE 7, x86_64, podman 5.4.2; arm64 and
                    riscv64 under qemu-user emulation
  cmake options   : -G "Unix Makefiles" -DCMAKE_BUILD_TYPE=Release (-O3 -DNDEBUG)
                    CMAKE_C_FLAGS="-g -ffile-prefix-map=<src>=vorbis-native-tools
                    -ffile-prefix-map=<build>=build"; the shim's CMakeLists adds
                    -fPIC -fvisibility=hidden and links with --no-undefined
                    --exclude-libs,ALL -z noexecstack --build-id=sha1;
                    then strip --strip-unneeded
  Reproducibility : all three Linux RIDs and android-arm64 were built twice on
                    2026-10-10 (before and after the licence-file change); the
                    shipped files were byte-identical both times.
  Gate            : ELF class/machine, SONAME, no RPATH/RUNPATH/TEXTREL,
                    GNU_STACK RW, exact export set, NEEDED system-only + ldd -r,
                    glibc floor CHECKED, build-id equal stripped/unstripped,
                    licence files exact, smoke test
