================================================================================
vorbis-native-tools/ogg and vorbis-native-tools/vorbis - VENDORED UPSTREAM SOURCE
================================================================================

WHAT THESE FOLDERS ARE
--------------------------------------------------------------------------------
Unmodified copies of the official Xiph.Org release tarballs of libogg and
libvorbis. They are the ONLY upstream source the codebrix_vorbis native library
in this repository is ever built from. No build step in this repository clones,
downloads, or otherwise fetches libogg, libvorbis (or anything else) at build
time - see README.txt for the rule this exists to satisfy.

The release tarballs themselves are kept, byte for byte as downloaded, in
upstream-downloads/, so the vendored trees can be re-verified at any time with
no network.

This file lives BESIDE the two trees, not inside them, so that ogg/ and vorbis/
stay byte-identical to their tarballs (not even an added file).

NOT MODIFIED
--------------------------------------------------------------------------------
No file in ogg/ or vorbis/ has been modified, renamed, reformatted, added or
deleted, and none ever should be. Verified on 2026-10-10 with the check below
(no differences, 135 files in ogg/, 428 in vorbis/).

If a future build ever needs a change to this source, it goes in
patches/*.patch and is applied by the build scripts into a scratch copy at build
time, never into these folders. As of 2026-10-10 there are no patches.

Note: the repository-root .gitignore would ignore ogg/win32/ and vorbis/win32/
([Ww][Ii][Nn]32/); vorbis-native-tools/.gitignore re-includes them so the
committed trees stay complete.

VERIFYING THE SNAPSHOTS AGAINST THEIR TARBALLS (no network needed)
--------------------------------------------------------------------------------
    cd vorbis-native-tools
    sha256sum upstream-downloads/*.tar.xz          # compare with the hashes above
    mkdir /tmp/xiph-verify
    tar -xJf upstream-downloads/libogg-1.3.6.tar.xz    -C /tmp/xiph-verify
    tar -xJf upstream-downloads/libvorbis-1.3.7.tar.xz -C /tmp/xiph-verify
    diff -r /tmp/xiph-verify/libogg-1.3.6    ogg      # expect no output
    diff -r /tmp/xiph-verify/libvorbis-1.3.7 vorbis   # expect no output

Re-checking the tarballs against upstream (optional, needs network - a
convenience for a human, never a build step):

    https://downloads.xiph.org/releases/ogg/libogg-1.3.6.tar.xz
    https://downloads.xiph.org/releases/vorbis/libvorbis-1.3.7.tar.xz
