THIRD-PARTY SOFTWARE NOTICES AND INFORMATION

CodeBrix.Audio.Vorbis is an Ogg Vorbis encoder for .NET: a managed wrapper
together with the native codebrix_vorbis libraries it P/Invokes into. Two
distinct things in this repository come from other people, and both are
covered below:

  1. THE VENDORED SOURCE. vorbis-native-tools/ogg/ and vorbis-native-tools/vorbis/
     are unmodified copies of the Xiph.Org release tarballs of libogg and
     libvorbis, committed to this repository so the native libraries can be
     rebuilt from it alone. The tarballs themselves are kept in
     vorbis-native-tools/upstream-downloads/, and their identity (URL, version,
     SHA-256) is recorded in vorbis-native-tools/UPSTREAM.txt.

  2. THE SHIPPED BINARIES. The package's runtimes/<rid>/native/ folders contain
     libcodebrix_vorbis.so / libcodebrix_vorbis.dylib / codebrix_vorbis.dll,
     each of which statically links libogg, libvorbis and libvorbisenc compiled
     from exactly that source, together with a small C shim
     (vorbis-native-tools/shim/) written for this repository.

Both libraries are licensed under the BSD 3-Clause licence, reproduced in full
below, which is compatible with this repository's own BSD 3-Clause licence.
One libvorbis source file additionally preserves an older permissive notice
(see entry 2); it too is reproduced below.

HOW BSD-3-CLAUSE CLAUSE 2 IS SATISFIED
    Clause 2 requires a binary distribution to reproduce the copyright notice
    and the licence "in the documentation and/or other materials provided with
    the distribution". Every native build copies libvorbis's COPYING file as
    LICENSE-Vorbis.txt and libogg's COPYING file as LICENSE-Ogg.txt beside the
    binary in runtimes/<rid>/native/, so both licence texts physically travel
    inside the NuGet package next to every native library, on every platform -
    in addition to this file.

WHAT WAS MODIFIED
    NOTHING. No file in vorbis-native-tools/ogg/ or vorbis-native-tools/vorbis/
    has been edited, renamed, reformatted, added or deleted. If a build ever
    needs a source change it goes in vorbis-native-tools/patches/ and is
    applied to a scratch copy at build time, and this section must say so.

WHAT IS NOT BUILT
    libvorbisfile (vorbis/lib/vorbisfile.c) and the examples, tests and tools
    in the vendored trees are vendored but never compiled. Decoding is the
    managed decoder in CodeBrix.Audio.Core, which is not part of this
    repository and carries its own notices.

WHAT IS NOT THIRD-PARTY
    The C shim (vorbis-native-tools/shim/), every build script, the managed
    library and the tests are original work of this repository. The test
    suite uses no recordings: every test signal is generated in code.
